# AGENTS.md

Instrucciones para agentes de codigo (Claude Code o Codex) en este repositorio.

- La guia unica del proyecto es `CLAUDE.md`: estado, comandos, arquitectura, reglas de dominio y operacion. Leela
  completa antes de cualquier trabajo; este archivo no la duplica ni la reemplaza.
- El plan vigente, su bitacora y su prompt universal son los que indica la seccion "Estado" de `CLAUDE.md`. Cada sesion
  toma el primer gate ABIERTO de esa bitacora y sigue el protocolo del plan (inventario y plan antes de editar, GO
  explicito del responsable, un commit por gate y detenerse).
- No se trabaja sin instruccion explicita del responsable. Responde siempre en espanol.
